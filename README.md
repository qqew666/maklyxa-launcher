# MaklyxaLauncher v1.6.0

Настольный лаунчер (`.exe`) для **официального** клиента Roblox.
Своё окно без рамки, три темы оформления, боковое меню с группами разделов.

## Что нового в v1.6

- **Полностью новый интерфейс**: боковое меню с группами «Запуск / Тюнинг /
  Система», акцентная подсветка активного раздела, шапка с брендом,
  версией и быстрым переключением темы, статусная строка внизу
- **Новая компоновка страниц**: крупные заголовки разделов, карточки
  с акцентной чертой, двухколоночный экран запуска и сетка 2×2
  для слотов курсоров
- **Обновлённые темы**: нейтральные палитры тёмной, светлой и стеклянной
  темы, свои чекбоксы и тонкие скроллбары вместо стандартных
- **Мягкое выделение списков** — выбранная игра или набор подсвечиваются
  оттенком акцентного цвета, а не сплошной заливкой
- **Удобнее курсоры**: кнопки «Применить набор» и «Вернуть исходные»
  подняты наверх, под список наборов

## Что нового в v1.5

- **Наборы курсоров** — вкладка «Курсоры» теперь менеджер наборов:
  список наборов, четыре слота (ShiftLock, обычная стрелка, стрелка
  в игре, IBeam), превью, создание, переименование и удаление
- **ZIP-импорт и экспорт** — наборы сохраняются в архив и загружаются
  обратно; формат совместим с наборами Froststrap
  (`MouseLockedCursor.png` + `Cursors/KeyboardMouse/`)
- **Получить текущий** — копирует курсоры из установленного клиента
  в выбранный набор
- Автоприменение выбранного набора и безопасный откат сохранены

## Что нового в v1.4

- **Свои курсоры Roblox** — замена стандартных PNG курсоров клиента
- **Автоприменение** — курсоры обновляются перед каждым запуском игры,
  в том числе после обновления клиента или через Froststrap/Bloxstrap
- **Безопасный откат** — исходные PNG сохраняются в резервную копию,
  кнопка «Вернуть исходные» полностью восстанавливает их

## Что нового в v1.3.2

- **Предупреждение о бета-рендерах** — при выборе Vulkan или Direct3D 12

## Что нового в v1.3.1

## Что нового в v1.3

- **Полностью новый интерфейс**: карточки вместо рамок, hover-эффекты,

## Возможности

### Игра
- **▶ PLAY** — запуск игры по Place ID или любой ссылке (`roblox.com/games/...`, `roblox://...`)
- Подтягивает **название, автора, иконку и сколько игроков сейчас в игре** (публичный API Roblox)
- **Запустить Roblox без игры** — открывает сам клиент; если он уже запущен — выводит его окно на передний план; иначе пробует прямой запуск `RobloxPlayerBeta.exe`, затем `roblox://`, и только потом сайт Roblox
- **Автоскачивание Roblox** — если клиент не найден, лаунчер сам предлагает скачать официальный установщик прямо с сайта Roblox (`www.roblox.com/download/client` — всегда последняя версия) с прогресс-баром и запускает его

### Флаги (как в Bloxstrap / Froststrap)
- **Ограничение FPS** — 60 / 120 / 144 / 240 / 360 или «Как в игре»
- **Графический API** — Direct3D 11 / Direct3D 12 / Vulkan / OpenGL
- **Качество графики** — уровни 1–10
- **Применять флаги перед каждым запуском** или кнопкой «Применить сейчас»
- **Панель бутстрапера** — читает и пишет конфиг Froststrap/Bloxstrap:
  - регион сервера (список из кэша дата-центров Froststrap)
  - Discord Rich Presence, детали сервера, подтверждение запуска, матчмейкинг,
    счётчик времени, автозаголовок окна и другие переключатели

### Наборы курсоров
- **Менеджер наборов** — вкладка «Курсоры»: список наборов, создание,
  переименование и удаление
- **Четыре слота** — ShiftLock (`MouseLockedCursor.png`), обычная стрелка
  (`ArrowCursor.png`), стрелка в игре (`ArrowFarCursor.png`) и курсор
  ввода текста (`IBeamCursor.png`)
- **Превью** — миниатюра каждого PNG, клик по превью заменяет файл,
  кнопка «Просмотр» открывает оригинал
- **ZIP-импорт/экспорт** — совместимо с наборами Froststrap
- **Получить текущий** — копирует PNG из установленного клиента в набор
- **Применение** — в версии клиента и в `Modifications` найденных
  Froststrap/Bloxstrap, поэтому курсоры работают и после обновления игры
- **Автоприменение** выбранного набора перед запуском игры
- Исходные файлы резервируются, кнопка «Вернуть исходные» откатывает замену
- Рекомендуемый размер — 64×64, PNG с прозрачностью

### Прочее
- **Избранное** и **история** запусков (двойной клик = запуск), недавние игры на главном экране
- **Настройки**: автозакрытие, игра по умолчанию, запоминание последней игры, 5 цветов акцента, тема, проверка установки, сброс
- **Журнал** всех действий

## Как это работает

Для запуска лаунчер не трогает игру. Он формирует стандартную системную ссылку:

```
roblox://experiences/start?placeId=123456789
```

её подхватывает зарегистрированный обработчик (официальный клиент или твой
бутстрапер, например Froststrap) и открывает игру. Ничего не внедряется —
это честный запуск, не нарушающий правила Roblox.

Отдельно, если включены наборы курсоров, лаунчер заменяет только PNG
курсоров в версиях клиента и `Modifications` Froststrap/Bloxstrap:
`content\textures\MouseLockedCursor.png` и
`content\textures\Cursors\KeyboardMouse\`. Исходники сохраняются в
`%APPDATA%\MaklyxaLauncher\cursor_backup`. Это локальное оформление, оно
не меняет код игры. Кнопка «Вернуть исходные» возвращает сохранённые файлы.

FastFlags пишутся **слиянием** в `ClientAppSettings.json` (Roblox,
Froststrap/Bloxstrap Modifications, рядом с exe): чужие ключи не затираются,
наши старые значения обновляются или удаляются при сбросе. Настройки
бутстрапера пишутся в его `Settings.json` — только известные ключи, остальное
сохраняется как было.

## Сборка .exe

```bat
pip install pyinstaller
build.bat
```

Готовый файл: `dist\MaklyxaLauncher.exe` (одиночный файл, Python не нужен).

## Запуск из исходников

```bat
python launcher.py                   # запуск приложения
python launcher.py --selftest        # автотест без окна
python launcher.py --page flags      # сразу открыть вкладку
                                     # game/favorites/flags/cursors/settings/log
python launcher.py --theme glass     # тема без сохранения (dark/light/glass)
```

## Файлы

| Файл | Назначение |
|---|---|
| `core.py` | ядро: конфиг, темы, флаги, бутстраперы, геометрия окна |
| `launcher.py` | интерфейс приложения |
| `make_icon.py` | генератор иконки (`icon.png`, `icon.ico`) |
| `build.bat` | сборка exe через PyInstaller |
| `dist\MaklyxaLauncher.exe` | готовое приложение |

Настройки и списки: `%APPDATA%\MaklyxaLauncher\config.json`
(старый `%APPDATA%\RobloxLauncher\config.json` мигрируется автоматически)

Наборы курсоров: `%APPDATA%\MaklyxaLauncher\CursorSets` (папка создаётся
при запуске, каждый набор — отдельная папка).
Исходные файлы для отката: `%APPDATA%\MaklyxaLauncher\cursor_backup`,
состояние замены: `%APPDATA%\MaklyxaLauncher\cursor_state.json`.

Читаются и обновляются также:
- `%LOCALAPPDATA%\Froststrap\Settings.json` или `%LOCALAPPDATA%\Bloxstrap\Settings.json`
- `%LOCALAPPDATA%\Roblox\ClientSettings\ClientAppSettings.json` и аналоги бутстраперов
- `<версия Roblox>\content\textures\MouseLockedCursor.png`,
  `<версия Roblox>\content\textures\Cursors\KeyboardMouse\` и аналоги в
  `%LOCALAPPDATA%\Froststrap\Modifications` / `Bloxstrap\Modifications`
  — только для замены курсоров

## Требования

- Windows 10/11
- Для запуска игр — установленный клиент Roblox (если его нет, лаунчер предложит скачать)
- Для сборки: Python 3.10+ и PyInstaller
