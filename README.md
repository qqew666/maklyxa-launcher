# Сайт MaklyxaLauncher

Статический лендинг лаунчера: информация, скриншоты и кнопка скачивания.

## Структура

```
site/
├── index.html                     # сам сайт (один файл, без зависимостей)
├── downloads/
│   └── MaklyxaLauncher.exe        # файл для скачивания
└── img/
    ├── dark.png / light.png / glass.png   # скриншоты тем
    └── icon.png                   # иконка в шапке
```

## Как открыть локально

Просто открой `index.html` в браузере — сайт полностью автономный
(HTML + CSS, без JS и внешних ресурсов).

## Как опубликовать в интернете

Любым способом, файлы загружаются как есть:

1. **GitHub Pages** — создай репозиторий, загрузи содержимое `site/`,
   в Settings → Pages выбери ветку и папку. Ссылка вида
   `https://<username>.github.io/<repo>/`
2. **Netlify Drop** — открой app.netlify.com/drop и перетащи папку `site/`.
   Готово, получишь ссылку.
3. **Любой хостинг** — залей папку по FTP/SFTP или через панель управления.

## Обновление версии

При выпуске новой версии лаунчера:

1. Замени `downloads/MaklyxaLauncher.exe` на новый билд.
2. В `index.html` обнови: версию в кнопках и заголовках, размер файла,
   SHA-256 (посчитай: `Get-FileHash MaklyxaLauncher.exe -Algorithm SHA256`).
3. При смене скриншотов — положи новые в `img/`.
