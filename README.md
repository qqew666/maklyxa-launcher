# MaklyxaLauncher v1.6.4

Настольный лаунчер для **официального** клиента Roblox: установщик `.msi`
с выбором папки или портативный `.exe`. Своё окно без рамки, три темы
оформления, боковое меню с группами разделов.

## Что нового в v1.6.4

- **Быстрый переключатель аккаунтов** — раздел «Аккаунты»: вход по логину
  и паролю или через отдельное окно браузера, аватар, дата последнего
  запуска и выбор активного аккаунта. Следующая игра запускается под ним
  через одноразовый тикет Roblox
- **Пароль не сохраняется** — на диск попадает только сессия Roblox,
  зашифрованная средствами Windows (DPAPI); вход через браузер идёт
  во временном профиле Edge/Chrome и не затрагивает основной
- **Своё ограничение FPS** — в поле можно ввести любое число от 1 до 1000,
  готовые пресеты остались в списке
- **Свои темы оформления** — раздел «Темы»: тёмная или светлая база,
  свой оттенок и акцент, картинка для шапки окна, живое превью и
  ZIP-импорт/экспорт. Наборы хранятся в папке `ThemeSets` так же,
  как наборы курсоров

## Что нового в v1.6.3

- **MSI-установщик** — лаунчер ставится как обычная программа Windows:
  в установщике можно выбрать папку установки (по умолчанию
  `C:\Program Files\MaklyxaLauncher`)
- **Ярлыки** в меню «Пуск» и на рабочем столе; удаление через
  «Параметры → Приложения» или «Программы и компоненты»
- Настройки пользователя в `%APPDATA%\MaklyxaLauncher` при удалении
  сохраняются
- Портативный `.exe` по-прежнему прикладывается к релизу — установка
  для него не нужна

## Установка

Скачайте `MaklyxaLauncher-1.6.4-x64.msi` со страницы
[релизов](https://github.com/qqew666/maklyxa-launcher/releases/latest)
и запустите. Установщик позволяет выбрать папку (по умолчанию
`C:\Program Files\MaklyxaLauncher`), создаёт ярлыки в меню «Пуск» и на
рабочем столе. Удаление — через «Параметры → Приложения» или
«Программы и компоненты»; настройки в `%APPDATA%\MaklyxaLauncher`
сохраняются.

Портативная версия `MaklyxaLauncher.exe` работает без установки.

## Возможности

### Игра
- **▶ Просто в Roblox** — главная кнопка: открывает сам клиент; если он уже запущен — выводит его окно на передний план; иначе пробует прямой запуск `RobloxPlayerBeta.exe`, затем `roblox://`, и только потом сайт Roblox
- **▶ Играть по ID** — запуск игры по Place ID или любой ссылке (`roblox.com/games/...`, `roblox://...`)
- Подтягивает **название, автора, иконку и сколько игроков сейчас в игре** (публичный API Roblox)
- **Автоскачивание Roblox** — если клиент не найден, лаунчер сам предлагает скачать официальный установщик прямо с сайта Roblox (`www.roblox.com/download/client` — всегда последняя версия) с прогресс-баром и запускает его

### Аккаунты
- **Быстрый переключатель** — список аккаунтов с аватаром и отметкой
  активного; двойной клик или «Сменить» делает аккаунт текущим
- **Вход по логину и паролю** — лаунчер проверяет данные через
  `auth.roblox.com` и сохраняет только полученную сессию. Если Roblox
  просит капчу или 2FA, используйте вход через браузер
- **Вход через браузер** — открывается отдельное окно Edge/Chrome
  с временным профилем; после входа лаунчер забирает cookie сессии,
  а временный профиль удаляется
- **Запуск под аккаунтом** — перед запуском игры лаунчер получает
  одноразовый authentication ticket и открывает клиент уже под нужным
  аккаунтом. Если Roblox уже запущен, появится вопрос, закрыть ли его
- **Безопасность** — пароль нигде не хранится и не пишется в журнал,
  сессия в `accounts.json` зашифрована DPAPI (только текущий
  пользователь Windows)

### Флаги (как в Bloxstrap / Froststrap)
- **Ограничение FPS** — 60 / 120 / 144 / 240 / 360, «Как в игре»
  или своё значение от 1 до 1000
- **Графический API** — Direct3D 11 / Direct3D 12 / Vulkan / OpenGL
- **Качество графики** — уровни 1–10
- **Применять флаги перед каждым запуском** или кнопкой «Применить сейчас»
- **Панель бутстрапера** — читает и пишет конфиг Froststrap/Bloxstrap:
  - регион сервера (список из кэша дата-центров Froststrap)
  - Discord Rich Presence, детали сервера, подтверждение запуска, матчмейкинг,
    счётчик времени, автозаголовок окна и другие переключатели

### Наборы курсоров
- **Менеджер наборов** — вкладка «Курсоры»: список наборов, создание,
  переименование и удаление
- **Четыре слота** — ShiftLock (`MouseLockedCursor.png`), обычная стрелка
  (`ArrowCursor.png`), стрелка в игре (`ArrowFarCursor.png`) и курсор
  ввода текста (`IBeamCursor.png`)
- **Превью** — миниатюра каждого PNG, клик по превью заменяет файл,
  кнопка «Просмотр» открывает оригинал
- **ZIP-импорт/экспорт** — совместимо с наборами Froststrap
- **Получить текущий** — копирует PNG из установленного клиента в набор
- **Применение** — в версии клиента и в `Modifications` найденных
  Froststrap/Bloxstrap, поэтому курсоры работают и после обновления игры
- **Автоприменение** выбранного набора перед запуском игры
- Исходные файлы резервируются, кнопка «Вернуть исходные» откатывает замену
- Рекомендуемый размер — 64×64, PNG с прозрачностью

### Свои темы
- **Менеджер тем** — вкладка «Темы»: список наборов, создание,
  переименование, удаление и экспорт
- **База, оттенок и акцент** — светлая или тёмная основа и любые цвета
  из палитры; акцент меняет кнопки, выделение и подсветку
- **Своя картинка** — PNG, JPG, WEBP, BMP или GIF до 20 МБ; картинка
  показывается в шапке окна с затемнением под текст
- **Живое превью** — миниатюра окна с выбранными цветами и картинкой,
  двойной клик по превью применяет тему
- **ZIP-импорт/экспорт** — набор переносится одним архивом
- Наборы хранятся в `%APPDATA%\MaklyxaLauncher\ThemeSets`, каждая тема —
  отдельная папка с `theme.json` и `background.*`

### Discord
- **Статус в профиле** — «Играет в MaklyxaLauncher» с текущим действием:
  меню, клиент Roblox или название запускаемой игры, плюс время сеанса
- **Настройки → Discord** — включение статуса, Application ID и кнопка
  «Создать приложение». Один раз создай приложение с именем
  `MaklyxaLauncher` на
  [discord.com/developers/applications](https://discord.com/developers/applications),
  скопируй Application ID и вставь его в настройки. Нужен запущенный
  Discord для ПК

### Прочее
- **Избранное** и **история** запусков (двойной клик = запуск), недавние игры на главном экране
- **Настройки**: автозакрытие, игра по умолчанию, запоминание последней игры, статус Discord, 5 цветов акцента, тема (включая свои), проверка установки, сброс
- **Журнал** всех действий

## Как это работает

Для запуска лаунчер не трогает игру. Он формирует стандартную системную ссылку:

```
roblox://experiences/start?placeId=123456789
```

её подхватывает зарегистрированный обработчик (официальный клиент или твой
бутстрапер, например Froststrap) и открывает игру. Ничего не внедряется —
это честный запуск, не нарушающий правила Roblox.

Отдельно, если включены наборы курсоров, лаунчер заменяет только PNG
курсоров в версиях клиента и `Modifications` Froststrap/Bloxstrap:
`content\textures\MouseLockedCursor.png` и
`content\textures\Cursors\KeyboardMouse\`. Исходники сохраняются в
`%APPDATA%\MaklyxaLauncher\cursor_backup`. Это локальное оформление, оно
не меняет код игры. Кнопка «Вернуть исходные» возвращает сохранённые файлы.

FastFlags пишутся **слиянием** в `ClientAppSettings.json` (Roblox,
Froststrap/Bloxstrap Modifications, рядом с exe): чужие ключи не затираются,
наши старые значения обновляются или удаляются при сбросе. Настройки
бутстрапера пишутся в его `Settings.json` — только известные ключи, остальное
сохраняется как было.

Запуск под аккаунтом: лаунчер расшифровывает сессию из `accounts.json`,
запрашивает одноразовый тикет у `auth.roblox.com/v1/authentication-ticket`
и открывает ссылку `roblox-player:1+launchmode:play+gameinfo:<ticket>+...`.
Тикет одноразовый, пароль для этого не нужен. Вход через браузер использует
временный профиль Edge/Chrome с отдельной папкой и удаляет его после входа.

## Сборка

```bat
pip install pyinstaller
dotnet tool install --global wix --version 5.0.2
wix extension add -g WixToolset.UI.wixext/5.0.2
build.bat
build_msi.bat
```

`build.bat` собирает `dist\MaklyxaLauncher.exe` (одиночный файл, Python не
нужен). `build_msi.bat` упаковывает его в установщик
`dist\MaklyxaLauncher-1.6.4-x64.msi` с выбором папки установки. Для MSI нужен
[WiX Toolset 5](https://wixtoolset.org/): он ставится как .NET-инструмент
и не требует прав администратора.

## Запуск из исходников

```bat
python launcher.py                   # запуск приложения
python launcher.py --selftest        # автотест без окна
python launcher.py --page flags      # сразу открыть вкладку
                                     # game/accounts/favorites/flags/cursors/
                                     # themes/settings/log
python launcher.py --theme glass     # тема без сохранения (dark/light/glass)
```

## Файлы

| Файл | Назначение |
|---|---|
| `core.py` | ядро: конфиг, темы, флаги, аккаунты, бутстраперы, геометрия окна |
| `launcher.py` | интерфейс приложения |
| `make_icon.py` | генератор иконки (`icon.png`, `icon.ico`) |
| `build.bat` | сборка exe через PyInstaller |
| `build_msi.bat` | сборка MSI-установщика через WiX |
| `installer\MaklyxaLauncher.wxs` | описание MSI: файлы, ярлыки, выбор папки |
| `installer\license.rtf` | текст лицензии в установщике |
| `dist\MaklyxaLauncher.exe` | готовое приложение (портативное) |
| `dist\MaklyxaLauncher-1.6.4-x64.msi` | готовый установщик |

Настройки и списки: `%APPDATA%\MaklyxaLauncher\config.json`
(старый `%APPDATA%\RobloxLauncher\config.json` мигрируется автоматически)

Аккаунты: `%APPDATA%\MaklyxaLauncher\accounts.json` (сессии зашифрованы
DPAPI), аватары: `%APPDATA%\MaklyxaLauncher\avatars`.

Наборы курсоров: `%APPDATA%\MaklyxaLauncher\CursorSets` (папка создаётся
при запуске, каждый набор — отдельная папка).
Исходные файлы для отката: `%APPDATA%\MaklyxaLauncher\cursor_backup`,
состояние замены: `%APPDATA%\MaklyxaLauncher\cursor_state.json`.

Свои темы: `%APPDATA%\MaklyxaLauncher\ThemeSets` — каждая тема хранится
в отдельной папке (`theme.json` + `background.*`).

Читаются и обновляются также:
- `%LOCALAPPDATA%\Froststrap\Settings.json` или `%LOCALAPPDATA%\Bloxstrap\Settings.json`
- `%LOCALAPPDATA%\Roblox\ClientSettings\ClientAppSettings.json` и аналоги бутстраперов
- `<версия Roblox>\content\textures\MouseLockedCursor.png`,
  `<версия Roblox>\content\textures\Cursors\KeyboardMouse\` и аналоги в
  `%LOCALAPPDATA%\Froststrap\Modifications` / `Bloxstrap\Modifications`
  — только для замены курсоров

## Требования

- Windows 10/11
- Для запуска игр — установленный клиент Roblox (если его нет, лаунчер предложит скачать)
- Для сборки: Python 3.10+, PyInstaller и WiX Toolset 5 (только для MSI)
